3.3 src/membership_filters.py  [EXPERIMENT A: APPROXIMATE MEMBERSHIP]
--------------------------------------------------------------------------------
- class BloomFilter(n: int, p: float, seed: int = 0)
  Standard bit-packed Bloom Filter using optimal bit count m = ceil(-n ln(p) / (ln 2)^2)
  and k = round((m/n) ln 2) hash functions stored in contiguous np.uint8 byte arrays.
  Methods:
    * insert_batch(keys)  - Sets k bit positions per key. Time: O(k).
    * query_batch(keys)   - Returns boolean presence array (0% FNR). Time: O(k).
    * memory_bytes()      - Exact RAM via bits.nbytes. Space: O(m bits).

- class CountingBloomFilter(n: int, p: float, counter_bits: int = 8, seed: int = 0)
  Dynamic Bloom Filter replacing 1-bit flags with 8-, 16-, or 32-bit unsigned integer
  counters to support deletions while tracking counter saturation overflows.
  Methods:
    * insert_batch(keys)  - Increments k counters per key with overflow detection. Time: O(k).
    * query_batch(keys)   - Checks all k counters > 0. Time: O(k).
    * delete_batch(keys)  - Safely decrements k counters without underflow. Time: O(k).
    * memory_bytes()      - Exact RAM via counters.nbytes. Space: O(m * counter_bits).

- class CuckooFilter(capacity, bucket_size=4, fp_bits=12, max_kicks=150, seed=0)
  Partial-key Cuckoo Hash Filter storing f-bit fingerprints in 2^r buckets of b slots.
  Computes alternate bucket via XOR: b2 = b1 XOR hash(fp), supporting dynamic deletes
  and random-walk eviction kicks without storing original keys.
  Methods:
    * _hash_and_fp(keys)  - Computes primary bucket b1, alternate bucket b2, non-zero fp.
    * insert_batch(keys)  - Places fp in b1/b2 or evicts up to max_kicks; records failures.
    * query_batch(keys)   - Checks both candidate buckets in O(b) = O(1).
    * delete_batch(keys)  - Removes matching fingerprint from b1 or b2 in O(b) = O(1).
    * load_factor()       - Returns fraction of occupied slots (alpha).
    * memory_bytes()      - Exact RAM via buckets.nbytes.

3.4 src/frequency_estimators.py  [EXPERIMENT B: SUPPORT ESTIMATORS & BASELINE]
--------------------------------------------------------------------------------
- class CountMinSketch(memory_bytes: int, d: int = 5, seed: int = 0)
  2D matrix (d x w) of unsigned 32-bit counters locked to exact memory_bytes (w = bytes // 4d).
  Guarantees one-sided additive error: f(X) <= f_hat(X) <= f(X) + eps*M w.p. >= 1 - delta
  (strictly 100% Recall; never underestimates).
  Methods:
    * from_epsilon_delta(eps, delta, seed) - Constructs w = ceil(e/eps), d = ceil(ln(1/delta)).
    * update_batch(stream) - Vectorized bincount accumulation across d rows. Time: O(d).
    * query_batch(keys)    - Minimum counter across d hashed positions. Time: O(d).
    * memory_bytes()       - Exact table RAM via table.nbytes. Space: O(w * d) fixed.

- class CountSketch(memory_bytes: int, d: int = 5, seed: int = 0)
  2D matrix (d x w) of signed 32-bit counters paired with +/-1 Rademacher sign hashes.
  Unbiased estimator E[f_hat(X)] = f(X) canceling collision noise via median across rows.
  Methods:
    * update_batch(stream) - Adds +/-1 signed counts across d rows. Time: O(d).
    * query_batch(keys)    - Returns median(sign_r * table[r, col_r]). Time: O(d log d).
    * memory_bytes()       - Exact table RAM via table.nbytes. Space: O(w * d) fixed.

- class CountingBloomEstimator(memory_bytes: int, k: int = 5, seed: int = 0)
  Counting Bloom Filter variant adapted for frequency estimation: 1D shared array of
  m = bytes // 4 uint32 counters returning minimum counter across k hashed slots.
  Methods: update_batch(stream), query_batch(keys), memory_bytes(). Time: O(k).

- class LossyCounting(eps: float)
  Deterministic streaming baseline (Manku & Motwani, 2002) pruning infrequent items every
  w = ceil(1/eps) stream updates. Guarantees f(X) - eps*M <= f_hat(X) <= f(X) (100% Precision).
  Methods: update_stream(stream), query_batch(keys), peak_memory_bytes().

3.5 src/metrics.py
--------------------------------------------------------------------------------
- compute_mining_metrics(est_counts, true_counts, n_txns, theta=0.01) -> dict
  Computes Precision, Recall, F1-Score, Support MAE, Max Support Error, survivor count,
  and true frequent count strictly BEFORE any second-pass exact recount.

  Evaluates the two-pass verification pipeline (exact recount of sketch survivors only),
  returning Verified Precision, Verified Recall, Verified F1, and Candidates Pruned (%).

- class RetailBasketRecommender(memory_kb=256, estimator='cms', min_support=0.01, min_confidence=0.30)
  Implements the 4-stage retail cross-sell architecture:
  1) Canonical key stream -> 2) Cuckoo Filter gatekeeper -> 3) Fixed-memory Sketch filter

4. KEY BENCHMARK SUMMARY (groceries.csv: 9,835 Baskets, 579,961 Updates)
================================================================================
- Experiment A (Membership):
  * Bloom Filter (p=0.001)     : 261.9 KB RAM, 0.100% FPR, 0.000% FNR (no deletes).
  * Counting Bloom (p=0.001,8b): 2,095.3 KB RAM (8x Bloom), supports deletes, 0 overflows.
  * Cuckoo Filter (b=4, 12-bit): 512.0 KB RAM (4.09x smaller than CBF), 0.116% FPR,
                                 2.50x faster queries than CBF, 97.55% max stress load.
- Experiment B (Support Estimation, theta=1.0%, 333 true frequent itemsets):
  * 64 KB  Single-Pass         : Count Sketch 51.66% F1 vs. CMS 0.70% F1 (4.97x lower MAE).
  * 256 KB Single-Pass         : Count Sketch 92.50% F1 vs. CMS 83.69% F1 (2.43x lower MAE).
  * 256 KB Two-Pass Verified   : CMS 100.00% F1 (99.69% pruned, 333/333 recovered, 125 rules)
                                 vs. Count Sketch 96.84% F1 (14 patterns missed, 119 rules).
  * Lossy Counting (eps=0.0002): 86.3 KB peak RAM, 100.0% Precision, 69.97% Recall (82.33% F1).
- Real-World Production Recommendation:
  * Count-Min Sketch + Pass-2 Verification (with Bloom/Cuckoo gatekeeper) is optimal for
    real-world retail frequent pattern mining; Count Sketch is optimal for strict single-pass
    streams under severe RAM limits.
